# Retail project data dictionary

## Source and intended use

The three CSV files in `data/raw/` are deterministic synthetic demo data generated by `src/generate_data.py` (NumPy seed `11`). The records do not describe a real retailer or real customers. Monetary fields are expressed in Indian rupees (INR).

The bundled sample contains:

- 800 customer master records (769 customers have at least one sales line)
- 120 product master records
- 14,992 sales line items across 6,000 distinct orders
- Order-date range: 2023-01-01 to 2026-10-31
- 46 calendar months represented in the monthly SQL export

## Files and columns

### `raw/customers.csv`

| Column | Description |
|---|---|
| `customer_id` | Unique synthetic customer key |
| `customer_name` | Synthetic display name |
| `segment` | Consumer, Corporate or Home Office |
| `region` | South, West, North, East or Central |
| `state` | Synthetic Indian state / territory assigned to the region |

### `raw/products.csv`

| Column | Description |
|---|---|
| `product_id` | Unique product key |
| `product_name` | Synthetic product name |
| `category` | Furniture, Technology or Office Supplies |
| `sub_category` | Product sub-category |
| `unit_price` | List price in INR before line discount |

### `raw/sales.csv`

Each row is a **sales line item**, not a complete order. A single order can contain multiple rows.

| Column | Description |
|---|---|
| `line_id` | Unique sales-line identifier |
| `order_id` | Order identifier; repeats across an order's line items |
| `order_date` | Date the order was placed |
| `ship_date` | Date the line/order was shipped; it is not a delivery date |
| `ship_mode` | Standard Class, Second Class, First Class or Same Day |
| `customer_id` | Customer key linked to `customers.csv` |
| `product_id` | Product key linked to `products.csv` |
| `quantity` | Units on the line item |
| `discount` | Discount fraction from 0.00 to 0.50 (for example, 0.20 = 20%) |
| `sales` | Revenue after discount, in INR |
| `profit` | Sales less the generated unit-cost estimate, in INR; excludes other overheads |

## Derived files

- `data/retail.db` is built by `src/build_db.py` and contains `fact_sales`, `dim_customer`, `dim_product` and `dim_date` tables. It is regenerated locally and intentionally excluded from the ZIP/Git history.
- Query outputs are exported to `exports/` as CSV files.
- Chart images are exported to `reports/charts/`.

## Working with another dataset

Replace all three CSV files with files that keep the documented column names and compatible data types, then run `python run_all.py`. Existing files are preserved by default. Run `python run_all.py --generate-sample` only when you intentionally want to overwrite them with the synthetic demo data.
